Burada şu ana kadar proje için yazılmış olan erken aşama yazılım dosyaları bulunmaktadır.  
Kodlar şu an aktif geliştirme sürecindedir ve henüz final hali değildir.

Şu an repoda bulunanlar
- Object class (object.py)
  Tespit edilen hedef/nesne için gerekli bilgileri tutan temel sınıf.
- Prioritization function (prioritization.py)
  Hedef önceliklendirme mantığı için ayrı dosyada yazılmış fonksiyon.
- Matching algorithm (matching.py)
  Balon ile hedef eşleştirme mantığı için yazılmış algoritma.
- Dataset hazırlık scriptleri  (DataPrep)
  - Videodan her N’inci frame alma  (frame_extraction.py)
  - Frame index takibi için `last_index.txt`
  - `last_index.txt` sıfırlama scripti

Önemli Not 
Şimdilik lütfen dosyalar üzerinde değişiklik yapmayın.
